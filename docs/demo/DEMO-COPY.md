# Demo copy

- **Title:** Ask Claude. Logic Pro does it. (Logic Pro MCP launch film, v3.19.0)
- **Description:** A real Claude Code session (Sonnet 5.5) drives a live Logic Pro 13 session over MCP from plain-language requests: it reads the session, sets the tempo, pans five tracks, starts playback, brings in the five parts of an original track one by one and adjusts the mix, then reads every value back. All 13 writes returned State A (verified). One continuous take at 1.0x; the film ends after the read-back and does not show the final stop request, which Logic 13 did not confirm (State C, see docs/media/README.md).
