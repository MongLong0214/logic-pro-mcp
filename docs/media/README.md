## How it was made

- Recorded 2026-11-21 on Logic Pro 13.0 (7801), macOS 26.3, Apple Silicon, UI language en-US, with the **published v3.19.0 release binary** (SHA-256 checked by `Scripts/demo/fetch-binary.sh`).
- **Client: a real Claude Code session.** Claude Code v2.1.323 with Sonnet 5.5, started by `Scripts/demo/record_claude_take.sh launch` with the release binary as its only MCP server (`--strict-mcp-config`), no user settings, hooks or plugins (`--setting-sources project`), don't-ask permission mode with only the logic-pro tools and the two MCP resource tools allowed, and one appended instruction: answer in one short sentence. `Scripts/demo/typist.py` typed eleven plain-language requests into it at a human pace; Claude chose every tool call and its arguments. `Scripts/demo/mcp_tap.py` sat on the server's stdio and logged every JSON-RPC line unchanged with the time it passed; every caption, before → after value and timing in the film is rendered from that log.
- **What happened before the first request.** Before the take, the logic-pro server was reconnected from Claude Code's `/mcp` menu (the tap's log file had been deleted while open, so the server had to restart to reopen it) and the screen was cleared with `/clear`. The `/clear` line stays visible at the top of the client window.
- **One take, 1.0x.** Both windows were captured at the same time with ScreenCaptureKit (`Scripts/demo/capture/LogicCapture.swift`): Logic's window at native pixels (3840x2100, 60 fps) with Logic's own audio, and the client's Terminal window (1087x750). Nothing inside the session is cut, sped up or retimed, including the time Claude spends thinking.
- **The film ends before the eleventh request.** The last request, "Stop playback.", returned **State C (`readback_mismatch`)**: on Logic 13 the server's stop pressed the control bar's Play button and the transport still read as playing, and Logic did keep playing until the song ended. Claude reported that it could not confirm the stop and did not press again. Because the film only shows changes that were made and read back, it ends after the tenth request (the read-back) and the end card follows over the music as it fades. The omitted request and its calls are listed in `Scripts/demo/motion/public/data/session.json` (`film.omitted`).
- **Motion graphics.** Remotion (`Scripts/demo/motion`), brand colours and fonts from logicpromcp.com. Camera moves and close-ups are virtual crops of the real footage. Masters are rendered as JPEG sequences and scanned frame by frame at 3 luma; a frame the scan flags is rendered again on its own and the master is re-encoded (the first render of this take had two frames of bare background, a Remotion capture glitch, at 33.85 s and 83.35 s).
- **Music.** "Signal", 120 BPM, A minor, 48 bars, composed for this film by `Scripts/demo/music/compose.py`. Every part is written from bar 1 and the session starts with all faders down, so each part is heard from the moment Claude raises its fader. Played by Logic's own instruments; the audio in the film is Logic's real output captured during the take. Licence: original work for this project, under the repository licence.
- **Sound design** is generated by `Scripts/demo/sound_design.py`: a quiet ambient bed (A minor) under the 52 s before Claude starts playback, when Logic makes no sound, thinning out before the first part comes in; one soft tick per answered call; a riser into the drums; whooshes into the cards. After the read-back, Logic's music fades out under the end card.
- **Mastering** (all files): high-pass, +2 dB around 90 Hz for the bass, presence and air, light compression (1.6:1 above -20 dBFS), a plain gain to -14 LUFS and an oversampled peak limiter. Measured by `build.sh check` on audio extracted from each delivered container (it also fails the build if an output has no audio stream): **-14.1 to -14.2 LUFS integrated, -1.6 to -2.1 dBTP true peak, loudness range 11.5 LU** for the full film (10.5 LU for the social and vertical cuts), no clipped samples, no silence gaps or clicks. The five entrances step up by +5.1 (Pad), +3.9 (Keys), +3.1 (Bass), +3.8 (Drums) and +3.0 dB (Lead), comparing the 2 s before Claude's request with the 2 s after the server confirmed the fader at its value; measured from the moment the request was sent instead, while the fader is still moving, the steps are +3.3, +3.4, +2.0, +3.3 and +2.6 dB. The loudness range is allowed up to 12 LU so that each entrance stays audible. These are objective checks, not a listening test.

## What is MCP-driven, and what is not

Shown as MCP calls Claude made: `project.inspect_session` (read-only; it is on the not-qualified list for Logic 13.0, `docs/qualification/not-qualified-logic13.json`, because its readback is not compared, and the film shows it only as a read), reads of `logic://transport/state`, `logic://mixer` and `logic://tracks`, `transport.set_tempo` (90 → 120), `mixer.set_pan` on all five tracks, `transport.play`, `mixer.set_volume` to bring in each of the five parts, and two more writes (Keys pan L16 → L35, Drums fader 0.59 → 0.54). All 13 writes returned State A (verified), none was a no-op; the median round trip, measured at the server boundary, was 488 ms (fastest 134 ms, slowest 1052 ms). The read-back of `logic://tracks` at the end returned every value just written (Keys 0.48 L35, Pad 0.43 R12, Bass 0.41 L4, Drums 0.54 R6, Lead 0.92 R19); its data was 2.1 s old, so it reflects the last writes, 14.8 s earlier. `logic://mixer` answered `mixer_not_visible` and is not captioned. `transport.stop` is **not shown** (see above).

Prepared by hand and not shown as AI-driven: opening the song's MIDI as a new project, which assigned the instruments; naming the tracks Keys, Pad, Bass, Drums and Lead and the regions; the key signature (A minor, from the MIDI); hiding the Inspector; hiding the Record Enable and Input Monitoring buttons in the track headers (display only; no track was armed, Logic only tints the selected track); turning off "Click while recording" so the metronome stays off and unlit (the server read `isMetronomeEnabled: false` throughout); saving the project; and raising Logic's audio I/O buffer for the 4K recording (restored afterwards). The start state was set off camera by `Scripts/demo/driver.py --scenario reset` (tempo 90, faders down, pans centred, metronome and count-in off); its `navigate.goto_bar` failed (the server would not send keystrokes while Logic did not own the keyboard), so the playhead was put back at bar 1 through Logic's accessibility bar field, also off camera.

Not claimed: the film does not say the server works in ten UI languages; live measurement exists for en-US and ko-KR only.

Retention policy: keep these files only while referenced by README or release documentation; replace them with new captures rather than editing in place. No Git LFS is configured for this repository (no `.gitattributes`); the files are small enough to commit directly.
