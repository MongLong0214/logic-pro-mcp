## How it was made

- Recorded 2026-11-20 on Logic Pro 13.0 (7801), macOS 26.3, Apple Silicon, UI language en-US, with the **published v3.19.0 release binary** (SHA-256 checked by `Scripts/demo/fetch-binary.sh`).
- **One take, in order.** `record_take.sh reset` puts the session in its start state (tempo 90, faders down, pan centred, count-in and metronome off), then `record_take.sh film` captures the take: read tracks and transport, set the tempo 90 to 120, pan five tracks, press play, bring each of five parts in by raising its fader on its bar, four mixing rides, a read-back, stop. Nothing is replayed from another take. The only edit to the footage is a cut of the 2 s the driver waits after its first reads, so the track poller can fill; it happens on a static frame.
- **Capture.** ScreenCaptureKit (`Scripts/demo/capture/LogicCapture.swift`) records Logic's window alone at native pixels (3840x2100, 60 fps, ProRes 422 LT) together with Logic's own digital audio output. No desktop, Dock or notification can appear. The 4K master (3840x2160, 60 fps, 57 MB) was rendered from it and is not committed.
- **Client.** `Scripts/demo/driver.py` is a **scripted MCP client**, not an LLM session: it sends the same stdio JSON-RPC calls an agent would and logs each request, reply and measured round trip. The transcript, timers and captions in the film are rendered from that log. The film says so on screen. A real Claude Code recording was not possible here because the recording worker may not start nested Claude processes.
- **Motion graphics.** Remotion (`Scripts/demo/motion`), brand colours and fonts from logicpromcp.com. Camera moves are virtual crops of the real footage; footage is loaded as a JPEG sequence so no frame can drop out, and `build.sh` fails on any isolated dropout frame. No clip is sped up or slowed down.
- **Music.** "Signal", 120 BPM, A minor, 24 bars (48 s), composed for this film by `Scripts/demo/music/compose.py`: i-VI-III-VII, open voicings, a contrast section (bars 17 to 24) with half-time drums, Gaussian timing and velocity humanisation and a sustain pedal on the keys. Played by Logic's own instruments (Studio Grand, Epic Cloud Formation, Simple Foundation, SoCal drum kit, Kensington). The audio in the film is Logic's real output captured during the take. Licence: original work for this project, under the repository licence.
- **Sound design** (risers, whooshes, hits, one tick per write) is generated procedurally by `Scripts/demo/sound_design.py`, so it carries no third-party licence.
- **Mastering** (all files): high-pass, bass cut, presence and air, glue compression and a limiter, then EBU R128 normalisation. Measured by `build.sh check` on audio extracted from each delivered container, which also fails the build if an output has no audio stream or is quieter than -30 LUFS: **-14.1 LUFS integrated, -1.6 dBTP true peak, loudness range 2.5 LU**, no clipped samples, no silence gaps or clicks. This is an objective check, not a listening test.

## What is MCP-driven, and what is not

Shown as MCP calls: `transport.set_tempo`, `transport.play`, `transport.stop`, `mixer.set_volume` and `mixer.set_pan` (all in the set live-qualified on Logic 13.0; `docs/qualification/not-qualified-logic13.json` lists the operations that are not), plus reads of `logic://tracks`, `logic://transport/state` and `logic://system/health`. The reads are not operations in that qualification list, and `system.health` itself is not a qualified operation: it appears only as a resource read. All 15 writes returned State A (verified); the median round trip was 252 ms and the slowest 1284 ms.

Prepared by hand and not shown as AI-driven: opening the song's MIDI as a new project, which assigned the instruments; the track order; naming the tracks Keys, Pad, Bass, Drums and Lead; the key signature (A minor, from the MIDI); hiding the Inspector; saving the project; and raising Logic's audio I/O buffer to 1024 (restored afterwards) because the audio engine reported System Overload at 128 while recording at 4K. Track creation, MIDI recording, plug-in insertion and bounce are not live-qualified on 13.0 and are not shown. Mute, solo and rename act only on the selected track on Logic 13 and track selection is not qualified, so parts enter by fader moves. `navigate.goto_bar` returned State B and is used only in the reset, off camera.

Not claimed: the film does not say the server works in ten UI languages; live measurement exists for en-US and ko-KR only.

Retention policy: keep these files only while referenced by README or release documentation; replace them with new captures rather than editing in place. No Git LFS is configured for this repository (no `.gitattributes`); the files are small enough to commit directly.
