## How it was made

- Recorded 2026-11-20 on Logic Pro 13.0 (7801), macOS 26.3, Apple Silicon, UI language en-US, with the **published v3.19.0 release binary** (SHA-256 verified by `Scripts/demo/fetch-binary.sh`).
- Capture: ScreenCaptureKit (`Scripts/demo/capture/LogicCapture.swift`) records Logic's window alone at native Retina pixels (3840x2100, ProRes 422 LT) with Logic's own digital audio output, so no desktop, Dock or notification can appear. The 4K master (3840x2160, 60 fps) was rendered from it; only the 1080p files are committed.
- Driver: `Scripts/demo/driver.py` is a scripted MCP client (stdio JSON-RPC) that sends the same calls an agent would, and logs each request, reply and measured latency. The transcript, timers and captions in the film are rendered from that log. It is a script, not a live LLM session.
- Motion graphics: Remotion (`Scripts/demo/motion`), brand colours and fonts from logicpromcp.com. Camera moves are virtual crops of the real footage. No clip is sped up or slowed down.
- Music: "Signal", 112 BPM, A minor, 36 bars, composed for this film by `Scripts/demo/music/compose.py` (deterministic MIDI with velocity and timing humanisation), played by Logic's own instruments (Studio Grand, Epic Cloud Formation, Simple Foundation, SoCal Drum Kit, Kensington). The audio in the film is Logic's real output captured during the take. License: original work for this project, released under the repository license.
- Sound design (whooshes, hits) is generated procedurally by `Scripts/demo/sound_design.py`, so it carries no third-party license.
- Mastering for the files: gentle compressor and limiter, then EBU R128 normalisation. Measured on the final mix: **-14.2 LUFS integrated, -1.0 dBTP true peak, 0 clipped samples, no silence gaps or clicks** (`Scripts/demo/qa_audio.py`).

## What is MCP-driven, and what is not

Shown as MCP calls, all among the 17 operations live-qualified on Logic 13.0 (`docs/qualification/not-qualified-logic13.json` lists the other 121): `transport.set_tempo`, `transport.play`, `transport.stop`, `mixer.set_volume`, `mixer.set_pan`, plus reads of `logic://tracks`, `logic://transport/state` and `logic://system/health`. Every shown write returned State A (verified).

Prepared by hand, not shown as AI-driven: the project (the song's MIDI opened as a new project), the choice of instruments, the track order, the Mixer view and window layout, and the Logic audio buffer (raised during recording to avoid an audio-engine overload, then restored). Track creation, MIDI recording, plug-in insertion and bounce are not live-qualified on 13.0 and are not shown. Mute, solo and rename act only on the selected track on Logic 13 and track selection is not qualified, so parts enter by fader moves, not mutes. `goto_bar` returned State B (position readback is bar and beat only) and is used only off camera.

Not claimed: the film does not say the server works in ten UI languages; live measurement exists for en-US and ko-KR only.

Retention policy: keep these files only while referenced by README or release documentation; replace with new captures rather than editing in place. No Git LFS is configured for this repository (no `.gitattributes`); the files are small enough to commit directly.
